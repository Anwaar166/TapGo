# TapGo Story Section

## Overview

This section presents the key benefits of TapGo through a scroll-driven
storytelling experience. As the user scrolls, the kiosk smoothly rotates
and moves horizontally while feature descriptions appear one by one.

## Features

### 1. No Hardware Cost

**Title:** No Hardware Cost

**Description:** No upfront investment is required to get started. TapGo
provides the kiosk hardware and software, allowing businesses to focus
on growth instead of technology costs.

------------------------------------------------------------------------

### 2. Fast Ordering

**Title:** Fast Ordering

**Description:** Customers can browse the menu and complete orders
within seconds, reducing queues and improving overall service speed.

------------------------------------------------------------------------

### 3. Reduce Waiting Time

**Title:** Reduce Waiting Time

**Description:** Self-service ordering allows restaurants to serve more
customers during peak hours while minimizing waiting time.

------------------------------------------------------------------------

### 4. Better Customer Experience

**Title:** Better Customer Experience

**Description:** A modern, intuitive ordering interface creates a
smoother and more enjoyable experience for customers.

## Animation Flow

-   Intro heading fades out while scrolling.
-   Machine rotates from an angled position to upright.
-   Machine moves left and right between scenes.
-   Each content block enters from below.
-   Previous content moves upward and fades out.
-   Each scene is controlled using JavaScript scroll progress.

## Technologies

-   HTML5
-   CSS3
-   JavaScript
-   CSS Transforms
-   Scroll-based Animation
-   `getBoundingClientRect()`
-   `window.scrollY`
